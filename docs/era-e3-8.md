# E3-8：千年原生复验与千人名册压测

这是两种不同的验收，不以合成名册冒充长期世界的人口，也不把在世人数当历史人物总数。三个数据来源都用一次性样本，没有读取真实用户存档、调用外部模型，或改变试玩站点。

## 真实千年演化

使用种子 1／灵潮丰年的实际 T34 原世界：老井真实完工、三席亲笔原采契、改道实际付费且货物已经走过并签收。之后由完整原生引擎逐月推进 **12,000 个真实月** 至 T12034／仙历 2003 年 10 月。不是固定日期跳转，不限制人物数量、不硬改寿数、不跳过底层时钟、户籍或历史。实际下达可执行的休养指令；T3634 后用 52 次真正修炼和 22 次真正冲关指令让原角色自行取得后续寿元。这里是控制动作的原生世界，**不是默认自主千年结果**，未启用远地年算或上界行程。

| 原生重新读验 | T34 起，每 1,200 月一次，共 11 个实际写入并立即读回的年代包 |

之所以称为一条连续演化线：分段严格读回的原生字节确实作为下一段入口，每个节点记前一真实摘要及同一规则指纹。另起一个 Node 进程，把 11 份原生负载、正式清单与前后摘要链重新读出验证，随后实际再推进一月；T12035 摘要两次相同：c415f17eb970c1250b477e28e98819437162e815a54ab0ddb742df03880e523b。全部阶段不占浏览器玩家分支。

真实存活的闻春岚在这一局已到化神、实龄 1167／原生寿限 2200，仍在原井。她看到了原 T5 公井、T12 旧采契、T23 实走格、T34 原生交货的同一条证据链。在另一份已核副本真正入世并实际付 2 灵石勘井，推进到 T12035，严格便携再读；原档保持原字节。证明的是从早期实据到当世实际角色、制度与可定位原址，不是同名推定。

## 独立名册压测

从已经验证的 E36 T3634 真实原生档另开实际隔离分析分支，**合成新增 1,200 条记录**（900 在世、300 旧代陨落），总历代名册 1,221、在世 915。地图有 8 个地点、3 个村镇、实有西中东三域，375 个地块；带 306 条年代凭据。完整便携包 1,595,337 字节。原分支、原始源文件字节前后相同，并非把 1,200 人追加进游戏。为验证同名，同样写「陆照」的已逝旧人与年轻在世者有两个精确 ID；T60 的原测试史料只归旧人，T59 不可见；地图只出现真正在世的同名者。

三次独立复跑，每项预热 50、测 500 样本。p95 范围（毫秒）：

| 查询／投影 | 实测 p95 范围 |
| --- | ---: |
| 常规名册末页检索 | 0.451–5.835 |
| 同名筛查 | 0.468–1.864 |
| 旧人的史料查询 | 0.101–0.128 |
| 新人无同名史料结果 | 0.055–0.105 |
| Canvas 数据投影和聚类 | 0.559–0.646 |

聚类把在屏 915 人投影为 15 个标记；这是数据计算，不是浏览器绘制或 Android 帧率。一次同名抽样最大 109.726 ms。三次带 Node/Vite 进程峰值 RSS 377,700–384,048 KiB，时间可能受 CPU 和 GC 影响，不承诺玩家设备的速度。项目不新增任何玩法人数上限。

## 已复现的容量边界

普通单世界 JSON 导入 8 MiB，年代单份快照 32 MiB，可续长局启动时各分支保留的不同快照合计 128 MiB。这是三类不同的文件校验，不等于人口限制。预检只测当前一份，不额外把全部历史复制到内存；只有实际准备启动时校验组合。若单份实测超过长局限额，本次不启动该条可续长局。

先前 E3-1 的真实百年大世界隔离测试：实际 T1201–T1207 的七份不同快照合计 127,494,893 字节，可封存原线；加实际 T1208，第八份使合计 145,900,820，超过 134,217,728，生产启动门明确拒绝。此时 T1208 单独 18,405,927 字节，合法；八份原记录都在，原世界实际还能继续到 T1209，另外只读回一份当前头不冒充恢复全部分支。该测试的 Node 进程峰值 1,790,284 KiB 独立测得，不是同一主测试或手机估算。

## 复现

生产脚本在同一引擎指纹下又实跑一次：同一原生末世和下月摘要、同一 11 份年代包的 6,447,636 字节；精简过程凭据后全部 7,077,778 字节。Node 峰值 468,412 KiB，62.703 秒；另起进程查验 456 毫秒。已有目录不覆盖，预期指纹不符不创建目录，未完成的包不能读作验收结果。

请在仓库根目录执行。生成千年链、另生成名册样本时使用**此前不存在**的新目录；审计读取前者生成的完整目录：

    ./node_modules/.bin/vite-node scripts/thousandYearAcceptance.ts ./千年验收-本次
    ./node_modules/.bin/vite-node scripts/thousandYearAudit.ts ./千年验收-本次

名册脚本接收 T3634 同名的年代清单和原生 JSON 的路径前缀（不带扩展名）。前缀以本次千年脚本生成的真实名称为准：

    node --expose-gc ./node_modules/vite-node/vite-node.mjs scripts/e38RosterProbe.ts ./千年验收-本次/t3634-era-1303-10-实际摘要 ./名册验收-本次

千年脚本另可传预期引擎 SHA-256，封两次相同输入但不同引擎不算同一次执行；独立读验默认比较当前引擎指纹。它不扩大浏览器单次 1,200 月入口，也不会替玩家删除任何档。
