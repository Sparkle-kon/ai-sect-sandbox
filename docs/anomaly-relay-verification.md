# 一场天变，三地闻钟：传播验收

- 原生对照（seed 1，灵息繁华）：第 36 月血月魔渊生出真兽潮，后续短幕不预填。第 37 月另一名修士实际在万仙坊市当面听到；第 45 月太虚剑峰才收到坊市修士的飞剑。
- 两种引擎共享天象和传播结算。镜头只读所选修士已知的第一手链条；地图还要求此地点获准显示，会目不从公开纪事反推旁人的私下收讯。没有直接传信的记录就没有对应短幕。
- 本地存档重开复现原场次。收信人之后实地迁往坊市、第 48 月听到更可靠的当面消息时，新的传闻会照原规则更新；笺上初闻仍是第 45 月的太虚剑峰。 若转述的版本已经替换、无法从保留的第一条来讯证明它的完整上游，普通传闻仍按原规则送达；会目不靠猜测补齐三地。
- 当前网页版是单机模拟，可选在线模型并不等同于多人游戏。本地存档重开不算多人断线重连；没有多人传输可用前，相关验收独立保留为未验证。
