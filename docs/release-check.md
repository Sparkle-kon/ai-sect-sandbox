## 复现操作

1. 从「更多 → 读档」建立种子 13071 的「万象初开」。返回掌门台，选醉剑小筑，不重抽弟子。给第一位弟子派「闭关修炼」，确认后对照回山汇报，重复三次。每轮都实际过月。
2. 从「九州修仙交流群 → 掌门发言 → 自由发言」用掌门号发一条话，先点「预览原话」，再点「确认发出」。检查名号和原文。
3. 应下三尺门赵掌门的来帖，再过一月，核对胜负、伤势和日期，并打开「看斗法」。只看到来帖或回帖不算完成。
4. 用「更多 → 读档」核验本机档位并保存。刷新后再次核验同一档位，点「读取当前版 → 确认执行」，检查原宗门、日期、群聊原文和比试记录。

## 问题与边界

- 三个宽度游戏文档均无横向溢出。竖向滚动条占 15px。1440px 游戏文档比外层窗口宽，桌面截图只截取了实际布局的一段，并非缩放或缩窄后的游戏尺寸。
- 桌面首次拖拽只选中了弟子，按实际画面确认落点再拖才成功。没有把第一次选中当作派工。
- 存档页仍使用 JSON、UTF-8、Tick 等术语，实际恢复不受影响；本次未测实体手机触摸。
- 抽查控制台只见云端 Chrome 扩展的元数据提示，未捕获到游戏警告或报错。
- 群聊使用离线对白。计时起点按表中各行标注，含工具操作间隔，不等于真人上手研究。
- 此记录验证的是游戏构建，不等于站点可匿名访问。后续发布沿用已有的私有预览站，不改变站点受众。
