# 炉边的一封释约书

> 掌炉人把第一件法器交到你手里，工钱已结。第二炉还没添薪。你可以问他：余下那件，便不做了吧？

试玩时先入世成当事人，在人物页打开原有的「工坊委制与品质交割」。一份实付的私人两件委托完成首件验收后，合资格的原签人可提议停作余件；另一原签人可以同意，也可以说照原约做。首页没有新入口。玩家确认只花 5 神识记下下月打算，不提前签字，不改托管；真正过月再核本人、原址、原约和余款。

| 这一月发生的事 | 原账怎样走 |
| --- | --- |
| 只是提出、对方谢绝，或提议到期 | 不因此停工或退款；原委托依原期限继续。 |
| 余件已经起工 | 较早的停作提议失效；实耗照旧。 |
| 原签双方在原址先后应允，余件还没起工 | 按原账结束，只把未耗、未付的托管退还原委托人。已交器物、实付工钱和实耗材料不重算。 |
| 首件验收未达原定门槛 | 实耗照旧，无达标器物入库、无工钱。“没有可交的成品”不等于“已释约”。 |

同一个回复月里，先起工与先同意会有不同结果，依真实行动顺序结算。已减件的停炉补签和已撤并的工坊公契不叠用这条私人释约。放着没人回，不会假作双方同意。只有原当事人能在自己的原账查看，翻旧篇也分「双方同意停作」与一般终止。没有新货运、评分或额外品质。

## 已验证的原生样本

种子 1，从原生开局依次采根、到坊、出资、接约。T14 首件真交；T15 原委托人提出；在 T16 原工匠应允的支线里，**只退 55 灵石与 2 株玄土根**，原器物、工钱和已经做过的工序保留。同源的另一支在 T16 谢绝，不因此退料；无人应允的分支到 T17 先记提议到期，同月没有退款也没有伪交割。真正轮转掉当月纪事后，从原生凭据仍可读回，旁人即使同名也看不到。

测试用模拟 JSON 响应核对双方精确选择，未调用付费模型。另验了两位附身原签者下月签字、存读一致与伪造目标拒绝。这里是仓库里的规则与界面，未发布到手机试玩站，未在实体手机试点。
