# E2-1 修士的日常抉择：三组实测

疲惫、性情、自己掌握的消息、当地有无实物和过去确实履过的约，都能改变日常选择。最近连续做过同类事务，会降低再做一次的权重。救急和已经承诺、目前还能执行的事务仍先核验。刚开局或没有确实已做记录的修士，不补造履历。首页不加选项。人物页旧的复盘候选效用分也不冒充当时的权重或模型理由。

## 怎样测

同一 Linux / Node 环境，两套离线规则逐月跑 48 个月，仙历 1001 年正月（T1）起，1005 年正月（T49）止，不作玩家干预。每组各跑两次：连续推进与第 24 月存读后再推进，两者的最终原生档摘要、实际行动计数均相同。没有请求外部模型。

规则分别是 E1-10 的 `62e5ec572bda61edbf4632e1ec0076ea73c414413ec804a0f507a1ffe99cda14` 与 E2-1 的 `45be2d295b2aa7aafbdbd6faf435bd8559af05f1d241abd0bf8de866e3322214`。重复率的分母是同一修士连续两个真实月份都完成日常行动的次数，分子是这两次同为同一类的次数。日常包括调息、修炼、交谈、游历、采药；缺月和因守备、围攻等无法行动的月份不算一对。统计与个人持久记录的判定不同，后者还要求已结算出实效。
