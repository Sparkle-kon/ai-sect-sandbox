# 故人留下的那件首坯

炉前留下的，是原工匠做过的一件首坯，不是一张新委托。原委托人去世后，余下的钱和料暂守在原单，既不让工匠继续开炉，也不先发给哪位亲友。这项只适用于已起一件首坯的私人单件委托，多件等仍按原规则。要等同一份遗产实际裁定，才知道谁能开口问这一句：「故人留下的这件，您可还愿替他做完？」

入世成已裁定的继承人，在原址的「工坊委制与品质交割」查看这张原单。本人提出续制，另一月仍须原来的工匠亲自应允。排令只记下月的打算，工坊钱和料不会当场改变。若应允，之后继续走原来最后一道工序，不重复收款或做首坯。验收通过才交给经裁定的原继承人；若未达原定门槛，不发器物，也不支付工钱。

原工匠谢绝、迟迟无人接手，或续制期限内没能完成，都只退未用原料，经原遗产的真实归属办理。没有指定结果时，不凭同名、亲缘猜想或玩家选中谁就把东西送给谁。已耗材料留在旧账。首页没有新增操作。

## 确认是同一件首坯

隔离种子 1 为复验把原委托人的初始年龄置于寿限前一年，没改寿限、日期、钱包、原料或合同。实际采根、到坊、生前指定和后来的申领分别走原规则；测试并非一个默认自主运行的存档。

- **T11 至 T13：** 实托 55 灵石与 2 株玄土根。T12 原工匠起坯实耗 17 灵石、1 株。T13 原委托人按原生寿元去世，仍留 38 灵石、1 株在同一个原单；遗产开放审理期间不重复记入总账，不发工钱、不继续该坯。
- **T18 至 T21：** 遗产真实裁定后，继承人在 T19 提出，原工匠在 T20 应允，T21 只接做原坯的最后一道工序。最后一道实耗 16 灵石和 1 株；达到原门槛时只交一件原器物，付原工匠 22 灵石。不改第一笔工序、原委托人或订单身份。
- **独立对照：** 若原工匠拒绝或有过同意但逾期未成，实退尚未动过的 38 灵石、1 株给原遗产，由原生裁定已存在的继承归属转交，绝不付新工钱。若真做最后一道但质量未过，所耗照旧，只退剩下 22 灵石，不交器物或付酬。

原单、裁定、两份待办和实际工作最终能严格读回；成功支再续一月与直接推进逐字节一致。确定性引擎及模拟认知 JSON 用同一个实地核准，不让模型修改继承人、账或工序。此轮没有发布手机站，也没有实体手机测试。
