- 在世以仍存活且气血大于零的稳定人物 ID 去重；历代入册也包含已故者；创世仍在以开局真实 ID 集合交集计算。在籍凡人取原生各村人口总和，含未成年，不重复计入借居或已入门修士。
- 掌门是**每月边界之间实际不同**的稳定人物 ID，记录旧人、新人、宗门、年月以及存在时的原生签署方式。它不是月内操作日志；史料不足不猜。详情见[原始六条观测记录](era-e1-2-samples.ndjson)。
- 秒数只累计实际调用逐月规则的本地用时，不含存档校验、浏览器渲染或传输，亦非实体手机性能。每份原生 JSON 先测真实字节，再单独导出、读回、重新导出及与原取样节点各推一月比较；续跑探针不会污染主测线。传统单档上限为 8 MiB，不是人物上限。
- 旧规则 600 月参考只用于识别差异，本次两条最长实测线均为 50 年，不代表百年已经可玩。

## 复跑

先安装当前项目依赖。无头采样不受手机单批快进 120 个月的界面限制。

```bash
npm run fastforward:benchmark -- --campaign --seed=2031 --profile=classic --months=120,300,600 --revision=$(git rev-parse HEAD)
npm run fastforward:benchmark -- --campaign --seed=2032 --profile=classic --months=120,300,600 --revision=$(git rev-parse HEAD)
```
