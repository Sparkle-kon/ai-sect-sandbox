# 坊中旧事，交到谁手里

一场斗法散了，人们记下的胜负却不一样。掌卷人可以照当地原据写下发生的事，也把两份署名说法留在纸后。他不替后来人裁掉其中一份，更不把故事写成全世界的年表。

入世成一位在场的修士，从原有的「藏书阁与故事」打开本人掌卷稿约。挑一则在此地能核的旧事，再选一位实际在场的掌卷人。只有原来两位当事人能看稿约和交付原卷。首页没有新增入口。每次确认只扣 5 神识排下月打算，不先收稿款或交卷；真过月再核对本人、地点、原约和原据。

| 真正发生的步骤 | 灵石和原稿 |
| --- | --- |
| 当面邀约 | 不扣钱，不产生稿件。 |
| 原掌卷人另月接约 | 原委托人出 8 灵石托管。 |
| 实地核写 | 托管实耗 2 灵石购墨。无论有无异说，此时都还没有交卷或付稿酬。 |
| 再下一月或以后当面交卷 | 原据和核写记录仍可验证，原掌卷人实收余下 6 灵石，原件只有一份。 |
| 谢绝、撤下、到期，或原签者去世 | 只退未耗款，没托管就不退。核写之后已实耗的墨钱不重记，不发未交稿的稿酬。 |

抄本只用原生记载能保真的本地斗法或赈济，署名传本分列；已有的真勘误单独列出，没有就不自拟。核写当月及之后的新传本不会倒灌进这份原稿，原有卷册和证词始终保留。不会因委写另发任何外部模型请求；若已开启普通认知模型，模型只能从原生动作中挑选，不能给出稿文、价格或交割结果。
