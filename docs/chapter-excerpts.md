# 藏书阁 · 摘下这一幕

不需要把整局存档交出去才能分享一段故事。到藏书阁打开故事正文，再展开「故事节选」。只选想留的场景，先看将会写进文件的文字，再确认下载一份普通文本。旧章、存档和自己扮演的人都不会改变；下载也不会把内容发给任何人。

节选不是原稿的复制品。每一幕要有仍可独立核对的公开原事，原地点、日期和当事人不能互换。没有独立原证、当事人限定、或不同版本冲突的内容不拿来介绍别人。界面只会告诉你有内容略去，不会用略去的标题、名字或私语反过来透露内容。没有选中的场景、分支备注、世界数据和原章手稿不进入文件。

每一幕分别留下自己的出处；把两幕都选上，不会说成一人换了地点，也不会补一句「所以此事导致彼事」。预览之后切换视角、回放、分支，或源事发生改动，需要重新预览确认。

## 公开出处如何核对

- 每幕必须同时有唯一的公开原事和相符的章内记录。确切日期、地点、顺序、原当事人和可复原的原文范围都要一致。独立原事被推演淘汰时，即使旧章仍可正常阅读，也不以章内副本补作原证。未知或秘域不能凭一个标题就被认作公开地点；原引证只附读者眼下确实可见的地点标签。
- 旧章仅存部分引语时，至多保留原来剪下的那段。原事与章内双方仍能核对才采用；不会用现存长版补尾，也不会拼合另一种润色。两处都公开的当句与实际人物的心念是分开的。原生和模拟严格认知 JSON 都用同一判断，下载另不请求模型。
- 文件名固定，不含分支名；这是一份无外链的 UTF-8 普通文本，不保存游戏、也没有发送对象。界面只报告是否已请求浏览器下载。分支、读者、时间或入选原据变化，会拦下旧预览而要求重新确认。
