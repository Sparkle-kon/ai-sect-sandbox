# 人再多，也能从名册回到一幕故事

打开原来的人物页和「修士名册」。主角由这条故事线的实证决定，不是玩家当前选中的人，也不是附身的化身。名册上单独保留已经确认的主角与当前选择；翻页或搜别的名字不会把他们藏起来，也不会多算一位。没有确认主角时，不指定替身。同名可以用实际宗门和年龄区分；年龄和宗门也相同时，列出的序号只区别这次名册中的同名条目，不代表新身份。

看到确有在场原据的角色，可以点「读此人的这一幕」。它打开那一场既有纪事，不会替角色下令、附身或推进时间。只认当前分支、当前帧的原身及对应事件；失去源证、翻回旧帧或切去另一条分支后，旧操作不会冒读同名人或另一场戏。首页依旧是原来的两个操作。

## 实际长大的世界

默认种子 0，离线 Utility 实推进 500 个月，无指令覆盖、区域年算或作者改写。T1 有 16 位在世修士、187 位凡人；T501 历代共 159 位修士、154 位在世、317 位凡人。新增的 143 人各有实际成年自愿入门收据，不是扩容时临时填的人。六份实体年代包能严格读回，每份的下一月与原帧继续逐字节相同。终档原生载荷 4,603,432 B，六档原生载荷合计 14,565,932 B。脚本在 Linux Node 完成于 49.624 秒，峰值 940,492 KiB；不是手机性能数据。[机器旁证](dense-roster-continuity.ndjson)。

在 T501，这条试验线的主角是 **杜清禾**，在第 20 月实际入门，原在名册第 3/20 页。另选第 8/20 页的 **苏雨桥**（第 158 月实际入门），能沿真实本人和真实见证，读到第 500 月叶连翘与苏雨桥在摘星天机台坐而论道。苏雨桥与杜清禾不是同一角色，也没有凭同名把别人的事挪过来。选择画面始终使用眼前存档，以上不是玩家现有存档的主角宣布。

另外在隔离的 1,307 人**合成压力样本**中，逐页核对零遗漏、零重复、同名分别可选；每页最多 8 个结果，另有最多两位已选或主角的简短快捷项，页大小不是世界人数上限。组件结构检查了搜索、触控目标样式和分支读令；这里没有实测实体手机、系统安全区或窄屏浏览器交互。隔离浏览器未连上这次预览，手机试玩站未换版。
