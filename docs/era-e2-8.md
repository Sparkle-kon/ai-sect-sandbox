# E2-8：在剧本里写下未来，而不是立刻开局

在「更多 → 查看地图、纪事与存档 → 世界 → 剧本编辑与复演」里展开「写下纪元条件」。可以从当前仙历新写，也可以打开本机上次保存的一份独立草案。这页不前推月份，不替换正在玩的世界，也没有载入或启动按钮。

1. 写目标年月。它必须晚于草案记录的起点，最多往后 1,200 个月。重开草案看见的是原起点；若当前世界已经走过目标，界面另作提示。
2. 选两至三项结构化设定。可以写寒玉灵脉衰竭、丹霞一支迁北或村落承载条件。地点和人名来自所记种子与谱系的可核对基准，不自动从正在玩的存档导出，也不保证他们未来仍在、同意迁居或有可划拨的财物。
3. 预览核对的是目前能确定的约束。地权、供养条件、名单、库银和村落已有居民分别检查。每项明确写「作者设定」，不是过去的实录。草案即使有冲突仍可保存重改；退出只丢未保存的编辑，不碰世界档或已经保存的草案。

经典谱系种子 2031 的同一份例案：从仙历 1001 年一月写到 1021 年三月，相差 242 个月。极北寒玉脉拟降为灵叶承载 0，丹霞想让三位列名者带 120 灵石去同址。剩余灵气为 50 时，种子基准未发现硬冲突，但仍须复查旧宗留守和现时资金；若把剩余灵气改成 35，则因同地供养不足冲突。把正在游玩的日期设为 1022 年一月再打开，原草案日期不变，同时提示目标已过。

三例分别本地保存并原样读回；正在玩的样本都停在原 T1，原存档序列化字节相同。额外测试核对了已有两个分支的存档快照和已有存档槽原始版本完全相同，以及旧版 V1/V2/V3 可交换剧本的编码与读回不变。真正生成未来世界是后续任务，不是这页检查结果。
