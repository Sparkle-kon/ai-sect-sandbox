# E1-9 随机创世复演实测

沿用「更多 → 世界 → 存档 → 建立新世界」的种子和谱系字段。「随机抽种」只填写种子，不替换原世界或切换谱系；「复制种子」只复制十进制数字，剪贴板受限时仍可手动复制。沿用对新世界的单独确认。手填范围 0–4294967295，含两个端点。

用 Node.js 24.22.3、Linux x64、离线 Utility 逐月推进。规则指纹 `1ef3ce8edc8e1bcad960f69c7a84851059231e0b8ea3c3f85c5d7c925aeb29f6`。四个种子都用 `fractured-frontier` 谱系，创世仙历 1001 年一月（T1）在极北寒玉脉执行一次实际赐宝，然后不再干预，逐月到 1005 年一月（T49）。每个种子独立重开，第二次在第 24 个已推进月份存读，最终档、公开及内部模拟计数全部与连续推进逐字节一致。历史外部模型响应不在本次复演保证内。
