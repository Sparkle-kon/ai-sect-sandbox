# E3-2：远处有了近事

首页仍是「继续」与「更多」。试验开启后，只有当前视角有权查到的真实接境，在原有「远地年算」折叠中显示。实际越界月、从哪月完整逐月展开及结束月份分开。从未看到凭证不表示事情没有发生。不同视角不能互借经历，报信人与收件人不会因为有个信封就知道承运人当前经过了哪里，货主也不会自动获得护卫的实时位置。

地域的展开不重跑已经发生的月份。不另造人物、关系、道路、实物、寄件、兵役或奖惩。原有身份、额度、交易托管与截止日期继续由原系统办理；多个因素让同一区域逐月时只合并为集合，不增加第二次行动或收费。新进入逐月区域的远地剩余计数遵循原 E3-1 年末规则，符合条件者才计入结算，不补造欠缺的当月活动。

## 验证过的来源

- 原生信使只有实走的旧、现通路游标和实际相邻地图格越界才得到凭证。它在人们行动前推进，故当月起生效。不能从原计划、绝密信件、假定直线或已清掉的步迹推测要去之处。
- 生效中的护卫依真实跨过的路径格和同一且已发运的货单核对。即使在交付行粮、签约的当月发生跨界，也必须有先前实付委托、原生签约记录和实走路径。货物流转在人物当月行动后推进，因此下一月才有完整当地逐月行动。
- 联军声明或会师时没有抵达凭证。实际入城门、在同一战争记录上转换状态并可核对实际抵达地点之后，下一月起展开。只有当事人或可物理核对到达地点的人可读，不猜战线道路。
- 同一真实人物经原生出行返回过去登记地域可开下一月近事。未赶上机缘也能真正抵达，不因没有随机事件就造一篇纪事。本人和在场、已有实际关系的观察者可读，只见同名或同地图格不足。

每条已证据化的近事至多追加一次。完整逐月跨度是三个月；私有关闭记录有 36 个月保留窗。这不让临时账目过期或提前，更不会二次支付。旧存档没有可选近事字段时照旧解码，严格的新档检查日期、来源、地图格、在场与实际行程的相容性。
