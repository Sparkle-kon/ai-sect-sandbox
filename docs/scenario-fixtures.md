# 剧本编辑与离线复演

在游戏里打开 **世界 → 剧本编辑与复演**。选择种子、创世谱系和最后回合，然后按顺序加上初始干预指令。先生成隔离预览，核对回合和结果，再确认用该结果开始新的在玩时间线。取消、导入失败或目标失效都不会替换当前世界。切换前建议另存当前进度；已有手动存档槽不会被清空。

**剧本不是存档。** 剧本只带生成种子、谱系、最后回合和类型化指令，不带当前世界状态、模型设置、密钥、私有思绪或自由文字。复演只用规则脑，不调用网络模型。应用后可以照常选择规则脑或结构化模型推演；新时间线从复演结果开始，不会伪造此前的分支快照。

## 一个可以导入的剧本

```json
{
  "format": "ai-sect-scenario",
  "version": 1,
  "ruleset": 1,
  "seed": 32,
  "profileId": "classic",
  "endTick": 4,
  "commands": [
    {"tick": 1, "command": {"type": "SPAWN_TREASURE", "targetLocationId": "loc-market"}},
    {"tick": 3, "command": {"type": "WHISPER_MIND", "targetCultivatorId": "npc-1", "cue": "caution"}}
  ]
}
```

- 文件最多 32 KiB，允许 1 到 120 回合，最多 48 条指令。指令的回合不得逆序；同回合按列表顺序结算。
- 预设：`classic`（万象初开）、`spirit-bloom`（灵潮丰年）、`fractured-frontier`（裂土边荒）。
- 支持赐宝（指定真实起始地点）、降雷（指定真实起始修士）、魔潮，以及有限的传音提示（`focus`、`rest`、`caution`）。没有传音自由文字字段。
- 执行时也检查目标。如果目标已陨落或不再满足指令条件，整个预览失败，不会保留前几条指令产生的局部结果。
- 相同版本、规则和剧本可复演出相同结果。若将来游戏规则发生不兼容更新，应使用能识别该规则版本的构建，不保证旧文件在任意版本上结果不变。不同剧本的出身标记也会隔离同种子时间线。
