# 一笔坊市交割，两人的路仍各自向前

两人已经各有来路，才会在同一笔真实交易里相逢。买家接走货，卖家收了钱；此后一人去与旁人论道，另一人走到别处。两个后续各写在自己的名字下，不写成一段合传，更不说一定是这笔交易改变了他们。

从原有「藏书阁与故事」展开「有据转折」。只有这个分支的本章原卷确有交割、两张本人挂单、真实成交凭据，而且两个人各有更早独立的主角证据，才显示相逢。托管但未成交、跨坊出发、换了同名买卖人、旧章不再有可核原件，都不算。仍保留当月完整明细时，要查货款与货物是否真的各到原手。

这里把先前独立的见闻和此刻买卖角色分开；能查到一位的后事也不替另一位补写。再会须另有更晚的原生交割：仅同月、同地点、同名或长得一样的纪事不够。若旧证只剩一部分，只显示仍能核实的内容。外地未知原文不因阅读此卡而展开；实际买卖双方可重读自己签过的坊市。不会更改人物、推进月份或切换附身，首页无新增入口。

## 从真实四百月原档复验

这次沿用上一轮封存的种子 0 原生 T401，未改天时、名册或既得主角证据。苏清寒从第 125 月走到第 391 月让出故事焦点；杜清禾从第 391 月获得自己的主角证据。之后只给当事人实地下达合法操作，其他人调息；不是默认全自主样本。
