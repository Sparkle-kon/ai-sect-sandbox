# 两队人在同一处山径停下

两队人各自付过路费，也各自走了路。真正站到同一处安全关口，一位领路人才能把自己的一株翡翠灵叶放进茶约，等另一位领路人亲自答应。只是在舆图上挨得近、曾在同一个坊市，或和对方同名，都不算碰面。

可用时，原巡礼卡上会出现「山驿分茶」，首页没有新增操作。附身排令只耗神识，茶叶要到实际提出邀约才从原人托管。下一月或之后同一处仍能遇见，对方同意才实用一株茶叶。两位领取各自真正缺少的气血，最多各回 5 点；其他同行者不跟着领。两队都不挪步，也没有替谁到站或补缴路费。

若谢绝、撤下、已分头赶路，或等到回复期限还无人应允，就只把那株未用的原叶退回端茶人。没有料就不请这席茶；没有人按下同意，就不写成两人分饮。

## 实际两队同行的复验

隔离种子 13071 只在开局安排四人的出发地、受伤状态和实有物资，没改日历、路线、到达或后续托管。T2 两队各自邀同行，T3 两名不同的同伴亲自应允，T4 四人各实付 8 灵石走到同一段路真正的内部关口。T5 端茶人托管 1 株翡翠灵叶；T6 另一队领路人亲自应约，实际消耗 1 株，端茶人只补足缺少的 3 点气血，另一位恢复 5 点，同行者和两条路线不变。

另一支先实走离开才失约；另验了亲自谢绝和 T8 无人应时的实际退还。没有一支把退叶记成回血或补助整队。确切访路、邀约及结算能严格读回，下一月复跑一致；掉换原队或伪写原位置会被拒认。Utility 和模拟认知 JSON 使用同一原生核准。界面是旧巡礼卡里的可选一步，未发布到手机试玩或实测实体手机。
