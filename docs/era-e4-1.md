# E4-1：界线不等于到过，更不等于谁占了地

先把现有下界三域认准。西境／中州／东境仍是稳定的 west、center、east；25×15 旧下界格分别为 135、120、120。域址写旧图页和原生格，不靠地点中文名，不改变现有人物、地形或井址。对照的两条真实相邻界线是第 8/9 列和第 16/17 列（列从 0 数起）。域名不暗示归某宗；具体地块和站点的权属按各自当前原记分开核看。原 E3 的区域年算仍需另行开启，不拿年算记录或地图绘制帧认定已到过。上界三节点与两阶旧门路也不是新增宏观地域；此阶段只验三域，没有虚设第四至第九域。

原生有路、路已走过、路已关闭由不同证据得出。只认真实原生路径上的连续相邻格、实际付过且确实踏到的本人路段，或实际原货脚程；只订路、支付、看动画、或持别人的路径都不能变成自己的「实走」。有确切巡礼点时，认人现在脚下，不能用出发地或看起来相同的名号代替。自己的过去实走也不自动让人知道之后远处有没有关路。旧北井那笔 T34 实际交货虽然有真实绕行格，却一直在中州，不能冒充跨域。
