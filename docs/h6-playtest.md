## 两次点击过月

- Chrome 实际页面（视口宽 **1348 CSS px**）：开青云杂役派，第一次给谢归燕派闭关；二月简报点回晨会后，点「沿用上月差事并过月」进入三月，再点「知道了，回晨会」。回到三月晨会后仍能看到谢归燕的闭关功课，未进入四月。弟子名册与右侧群聊同屏可见。
- 360/390 px 模拟 DOM 同样显示全员简报与单一结束按钮；这两组尺寸测的是布局和实际 React 控件，不是实体手机触控。
- 两次点击指已有至少一件有效的上月差事时的最短路径。新开局、重新分工、主动查看人物或答复续集都可以另行操作。
- 连续轮换中实际来访的月份另走了一遍界面：同一位访客的旧事先在简报内出现；点回晨会后，同一月只保留一张来客卡；点沿用才进入下一月，上一位客人的话从当月卡上收起。续集抉择操作单列。
