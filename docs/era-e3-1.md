# E3-1：远地年算试验

从「更多 → 查看地图、纪事与存档 → 世界与设置 → 存档、世界种子与推演速度」进入「远地年算」。默认不启用；选修士已经见过的地点后，须另外确认才修改当前分支设定，不推进月份或改动其他分支。角色附身时，以身体所在的实际地点或通路关口为准。地图仅在既有工具展开且该地点真正已知又可见时标记区域，不以关闭迷雾获得权限。

## 算法边界

- 使用地形列划分三个稳定地区：西境、中州、东境。持久记录人物首次登记区、固定地点与聚落所在区、实有地脉位置，以及正式开通的道路和已开始、受领的真实路线跨区范围。首次登记不等于出生地，随移动变化的当前所在区也不是首次登记区。路线标记是已登记路段，不推断无脚印的商路，也不授权看地图隐蔽路线。
- 时钟、天气、灾害、家庭、村落人口、物资、制度、临场旅程和到期业务仍走原逐月规则。只对位置明确、身体状态安全、没有实际义务的远地修士省略可选行动。近区、玩家指令、已交付的模型候选、主动义务和优先救助不以远地年算代替。LLM 排队前也去掉当前快照已可确定不必问模型的外地修士；如果推进过程中情况改变，权威模拟仍可按月用 Utility 解决。
- 年末从真实省略的人月结算有限的灵气和气血。一个非近区个体一年至多有十二个人月；新近区、已经有当月正常行动、已故或因新状况不再合格的累计月份明确记入「未补算」，不伪造修炼、死亡、事件、关系、物品收入或账单。重新读档不会补发已经结过的月份。年度面板仅保留最近十二个年窗口中的统计。
- 近区依然走原决策，但由于各角色共享世界随机流和互动，整体数值、角色选择乃至生死都不承诺与全逐月相同。已有存档没有这个字段时照旧运行，本项不设修士数量的游戏上限，不作千年性能保证。

## 同种对照

用实际引擎从默认种子 **2031**、**万象初开**开局，关注太虚剑峰，从原始同一月分别推进 24 个月。具体数值也由测试固定并显示在试验设置里。

| 期末量 | 逐月参照 | 远地年算 |
| --- | ---: | ---: |
| 在世修士 | 20 | 19 |
| 村镇人口 | 206 | 208 |
| 宗门及人物持有（非流量）的灵石 | 36,806 | 36,826 |
| 地点与人物持有的玉叶草 | 48 | 44 |
| 收录的纪元事件凭证 | 3 | 2 |

月底日期相同。东境在第一个年末实际结了 33 人月、第二个年末 36 人月，共增加 69 点灵气；未产生额外事件或交易凭证。初始真实人物 ID 均能在年算史中找回，死亡不会移除旧身份。

另从种子 **70 / 灵潮丰年**共同原生进度 T6 开始。原确实支付 5 灵石的 npc-2 在中州极北寒玉脉，西境关注点之外。在无外加决策的两条 Utility 线，均于 T8 实际完成原待办，未延后到年末、未二次收费。到 T18 时两边仍为仙历 1002 年 6 月、22 个已登名修士、206 位村民，但在世修士 **21 / 22**、宗门存石 **24,775 / 24,417**、地点玉叶草 **34 / 39**、死亡 **1 / 0**、突破 **37 / 36**（逐月 / 混合）。远地在 T12 实结东境 **23 人月 / +23 灵气**。两线分别严格读回并续跑，下一月的便携保存字节各自一致；两线之间的随机状态不同。结果不是对未知种子、未来人口或速度的保证。
