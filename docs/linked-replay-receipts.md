# 本地复演回执链

先各自做完两次**手动**本地复演。保留第一张回执；保存第二张时，明确择第一张作它的前序。再在原时间线的回执工具里自己选两张，核对中间那一轮是否真能接上。不需要上传存档、另跑一次世界或把旧结果套回当前局。

对得上，表示前一回执记录的结束点，与后一回执独立读到的真实起点完全一致；也表示前序回执确为此前明记的那一张。不是日期相近、同一名字或数字碰巧一样，就自动算两段相接。

这项核对也要求后一段的终点已有独立的、确实留存的快照。还没走到、旧快照已被时间线腾掉，是「检查点未留存」，不是新一轮失败；当前没有原来的规则版本，则是「规则版本不可用」；原字节或前序关系对不上，才说不相符。核对不补造展不开的月份。

两张回执只在当前打开的本地工具里保留，不写进世界存档。界面列的是回执序号和月份，不列分支名称。重开或切换整个游戏存档会清掉这组回执；同种子重新开局，即使形成相同字节，也不承接上一局的回执。试验覆盖的只是普通规则引擎的两段本地复演，不是模型对话或任意旁线结果。
