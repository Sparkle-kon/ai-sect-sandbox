# 一个炉口，两个人的工序

掌炉人请来两位有资格的修士。先开口，不先认功。等两人分别答应，原承办人才把实有的工料封入炉边。第一个人落锤打坯，下一次由另一个人接这**同一件**坯做最后一道。谁实际干了哪一步，工坊卡就写谁的名字。

原工坊卡只在身份、炉位和用料真的满足时显示这项。附身排令只是下月打算，确认不会当场落锤、扣工料或发练功进度。未亲做过的工序没有自己的署名；不合格的终件没有器物。退出或到期，只退原托管的未耗部分，不重做原坯或补给新材料。

## 实物和署名

- 原宗门有在用公炉，实际掌炉人与两名有资格、同地在场的修士才可立约。由两人各自应允，最后一份承诺落实才封 55 灵石、2 株玄土根。暂时离开不能远程落锤；到期、实际失去承办资格或退出按原托管结清。
- 首人占用一个真实铸造炉位，耗 28 灵石、1 株玄土根，只写制坯署名，熟练度最多加 1；另一人至少另过一月，占用真实炉位，耗剩余 27 灵石、1 株玄土根。终验按本人开工前的熟练度、炉级、灵根和气血算；本人达标才最多加 1，同一枚坯也只交付一件法器给原承办者。新法器上可查实际两道工序。未过验仍是真实耗材，不补造法器、熟练度或署名。
- 发出邀请或预约不扣物资；已经打坯而后逾期，首段实耗不退，只返 27 灵石、1 株根。只有原三名参与人能查私约，旁人同址也不能看到。首页没有新键；原工坊卡负责查阅和次月排令。
