# E3-3：遗物、签书与亲历者能到当世

从现有「纪事 → 藏书阁与故事 → 查阅年代旧事」进入。能核对的原件、本人实际听到的转述、在场亲历者以及彼此不合的两份署名说法分别呈现。只能看见符合法定来源和当前视角的选项，不会自动导航、移人物、支付费用或给某个版本判真。舆图的原有工具里，只有角色实际在场且能核对实物或问到亲历者，才标一行「此处有本人可以核查的旧事凭据」。关掉迷雾不能扩大资格。

- **器物是原器物。** 从两枚互补的原生碎片重铸，能追到具体碎片、锻造年月和守约展示。旧凭据不等于东西还在。实物仅本人持有或当前实地合法观展时可核看，遗失、异地或已撤展不凭同名替代。
- **合同是当时签的。** 只有双方实际出资并成立的原契留下契据；一方看见自己的签书只证明签过，不证明交付、获偿或仍欠钱。第三人不能以在同一地图格取得私契。历史保存并不重建托管。
- **人是同一个人。** 见证标到实际人物 ID 和原事件。转述不同于亲历，远处看不见活的亲历者；能在同处核证时才有当面的选项。公开旧说以确实通过原生勘误系统登记的签名为凭，异口可并列，独立勘误有凭才标，不由系统补写旧谈。旧档没有亲历、原件或签约证据时如实缺失，不能按名字、目前境界或原事件标题补造。
- **凡人迁走后仍是原生日。** 只有已经真实发生的出生批次开始追踪，18 年后成熟，活到原生 72 年（这局设定，不是现实推论）才在其现居地照实记寿终。历史初始成年人的年龄仍未知。迁徙、募名、退名、灾亡在同一个人口内扣记，不凭年代推断家谱或更改既有个体。普通人口不增加设定上限，修士寿数仍用原规则。老化不是灾害，不冒名给当月少量新生补成同一个人。

## 独立原生样本

以下是多组可复现的受控原生样本，不是把不同档案拼成一件历史：

- 种子 11321 的实地收集两块碎片、实耗锻材重铸星衡合璧，真实挂展后现地另一人可核看，外地不可。可移交的精确器物凭证严格保存读回，重复碎片造假被拒。
- 种子 11621 的实际原签以 48 灵石价款和 24 灵石质押成立，签约者仍能读契约，未观察到交付则不写交付。篡改价款的存档拒收。
- 种子 106 实付赈济后，确实登记两份不合的公开读法，一人原生听到转述，外地无共同当事人的旁观者没有权限。另一份同种独立样本用真实全引擎推进 300 个月，留下太虚修士的准确 ID，实际经历 25 次原生新年年龄增长，使用固有寿元。他随后走到另一境，另一位仍在世修士只有在同处才能当面核听 1001 年 1 月赈济。各档独立严格读回。
- 凡人样本在第 13 与 25 轮有两次实际出生，第 229 轮原批次三人年龄达 18。第 231 轮四人从松灯坊市外村实际迁到万仙坊市外村，其中两人来自同一个第 13 轮已登记户籍批次（另两人的过去年龄未知）。第 877 轮原生日到寿，万仙坊市本地正常寿终五人：其中两位就是迁来者，另三位原本就住当地。同期实际新增三名，人口净由 300 变 298，不把五次死亡写成净少五人。第 876 轮的 191,236 字节便携原档回读后下一月逐字节相同，没有伪造灾难或重复扣账。该长例实际逐月运行原生村镇/户籍/人口模块，未将它说成全部世界运行 876 轮。
