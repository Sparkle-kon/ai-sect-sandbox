# E2-4《丹荒之年》：留炉、走镖与签收

从经典谱系种子 2031 的原生短缺局面继续：仙历 1009 年十二月，丹霞弟子韩立风有两株可动用的私藏翡翠灵叶，万仙坊市外村家户甲的顾兰舟正是求药人。对照沿用同一场短缺、原诊和当事人，只为可控试验设置弟子起始私藏两株；炼成与炼坏两线分别控制本轮随机输入。没有免费生成押运、药效或签收。
