# 月度回合的五个阶段

`advanceWorldTick` 仍是调用入口。阶段和它们的约定集中在 `src/engine/tick/`，可以按职责查找，不必继续往入口的长函数里加分支。

1. **PreTurn**：复制本轮世界，确定随机源，推进日历，完成回合准备。
2. **MovementAndEncounter**：处理原来就在人物行动前发生的世界移动、路途事件与前置结算。先结算灾害，再分配炉位。
3. **ActionAndCombat**：依原顺序逐位处理修士。每位修士的移动后果、行动及其见证仍在本次处理中落定，然后才轮到下一位。不要把逐人移动挪到全体行动之前。
4. **InstitutionAndWorld**：处理制度、生产、宗门事务和全局追踪。同批系统产生的事件，仍按原顺序完成整批后才进行需要整批完成的见证处理。
5. **ChronicleAndPostTurn**：处理编年、观察回调、结案与地图表现。原始月度事件、界面保留的近期事件、结案回调看到的事件不是同一个集合，不能随意合并。

接入新系统时先选职责所在阶段；如果它改变谁亲历事件、分配前的状态、随机调用或归档时点，先加针对这些边界的原生测试。拆分回归用同一批原生初态对照旧实现，比较存档字节、随机状态和有序事件/回调。
