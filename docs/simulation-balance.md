# 无头平衡验收

`npm run verify` 包含确定性长程回归。也可以单独复查实测结果：

```bash
npm run balance -- --ticks=500 --seeds=0,2031,4294967295
npm run balance -- --ticks=1000 --seeds=2031
npm run balance -- --tune --ticks=250 --seeds=0,2031,4294967295
```

每条样本从指定种子启动、使用同一个真实游戏推进引擎。默认是离线规则脑，不联网或调用付费模型。读报告时将双方宣战状态与已结束的单次围攻分开：胜利或击退意味着围攻结算，不意味着两宗议和。窗口末尾刚发起的战事也不是超期；独立的合法围攻用例检查它是否在有限回合结束。

候选调参只在隔离的无头世界中试算，并输出比较和建议。它不会修改线上默认值、已运行世界或存档。即使样本通过，也不能证明未知种子、所有配置和无限长运行都平衡；尤其是少数种子会严重减员。用额外种子检查建议，再决定是否修改玩法。
