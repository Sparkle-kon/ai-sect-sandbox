# P19–P22 剧情触发审计

**阶段报告。G1-3 尚未验收完成。** 有选项不等于已经发生剧情。以下只把真实行动和原始结算记为触发，不为凑数补写关系、战局、行踪或见闻。需要玩家发起的玩法，在无人干预局为零不代表不能玩。

## 不应强行补齐的前因

- 四个 300 月种子各有 296 个月出现自然产生的主角，合计新开 7 段主角故事、3 人自然淡出。没有当前主角正式悬赏、公开死亡或飞升退场。逃亡和正式交接不能通过捏造罪名或退场来完成。
- 候选版拜师线已有 13 次真实请求、6 次明确拒绝、1 次离开，无实际重逢。另一候选让双方独立去坊市，实测 3 次离开、无真重逢，没有代人找出不该知道的去向。
- 另四局候选中，5 次阵破有原件；规定的后 8 月内原守方离场只有 2 个角色月，均无可推荐的既知安全路。不会把险地标作安全或代角色回山。

## 如何复跑

四个独立种子是 0、51、709、13071，各 300 月，不可拼接成单局百年。十种子对照再加入 3、11、42、2026、4242、41005。比较同一位置前后的相同种子、玩法设置和月份，不拿不同世界互充前后。

在对应源码与依赖下可运行。第一条输出完整触发数，第二条额外列出主角、问证、战后和异象分别卡在哪个阶段：

```sh
./node_modules/.bin/vite-node scripts/storyTriggerAudit.ts --seed=13071 --months=1200 --lane=autonomous
./node_modules/.bin/vite-node scripts/storyTriggerFunnelRun.ts 13071 300
```

`--lane=scripted` 只挑当月确有的导演选项，不等于玩家操作。实际手机触控、键盘和两个真实在线客户端的断线重连需要各自验收，不能以离线模拟替代。
