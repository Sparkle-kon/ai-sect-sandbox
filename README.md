# 天道沙盒：AI修仙宗门与群像模拟器 (AI Sect Sandbox)

一个结合 **WorldBox + 鬼谷八荒 + 斯坦福 AI 小镇 (Generative Agents)** 的可视化沙盒修仙模拟器。
支持 **离线规则脑** 与兼容模型接口的 **结构化 JSON 决策**。不配置模型也可玩。仓库按 [开发规则](AGENTS.md) 和 [任务队列](BACKLOG.md) 逐项开发、验证和提交。

## 怎么玩

默认先读故事：先看本局主角（还未从实录中出现时显示「主角未定」），再看当前这一幕。点「继续」推进一回合。「上一幕」只是回顾，不会把旧情节当成新的。

想查地图、人物、纪事或亲自干预时，再点「更多」。手动存取在「更多 → 世界 → 存档」；「回到故事」沿用同一局当前进度，同时停止自动推演。

## 核心特性
- **2D 宗门与灵脉沙盒地图 (`WorldMapCanvas`)**：实时渲染宗门驻地、游历轨迹与事件。窄屏会把挤在一起的可见修士合为带人数的标记；点开可搜索、翻页和选人，迷雾外的人不会计入。
- **动态因果与恩怨关系网 (`RelationshipGraph`)**：图上只画当前选中人物的一小圈直接关系。完整关系按页查询，仍保留师徒、道侣、同门和血仇等实际记录。
- **双模式 AI 修士大脑 (`llmBrain.ts`)**：每个 NPC 拥有独立性格、功法、记忆流、虚构角色内心独白与行动决策。
- **天道干预控制台 (`GodConsole`)**：作为“天道/老爷爷”随时降下九天神雷、赐予天材地宝、发动魔道入侵，或向指定修士脑海灌输流言密语。
- **创世与剧本**：选择种子和创世谱系，也可以在「世界」里用[可交换剧本](docs/scenario-fixtures.md)离线复演一组干预。

## 快速开始

```bash
npm install
npm run dev      # 启动可视化沙盒界面
npm run verify   # 运行 TypeScript 类型检查 + Vitest 单元测试 + 生产构建校验
npm run map:benchmark # 测量 48/526 人窄屏场景的可见标记规划，不是设备帧率
npm run history:benchmark # 在 Node 分别测量完整快照集合的堆增量和单个存档的 UTF-8 字节数
```

## 长局档案与存档预算

在「纪事 → 藏书阁与史书」打开折叠的「远纪档案」可翻看旧章节。仍被有效事项引用的章节保留在近期档，书签引用的旧章节不会因远纪留存额度而被清掉。远纪资料在同一时间线的多个完整快照之间共享不可变副本，不合并或删除人物。

运行 `npm run history:benchmark` 会用 48 / 526 人的合成场景保留 16 个完整快照，分别报告 Node 垃圾回收后保留的堆增量与单个存档的实际 UTF-8 字节数。这不是手机内存或帧率。在一次 526 人环境测量中，堆增量从 17,481,704 降到 9,595,440 字节；同一存档仍是 1,300,011 字节。游戏内可在存档面板按需量当前文件字节数。8 MiB 是单个导入/导出文件的体积限制，不是人物人数上限。

## 如何在同一次执行里连续开发？
把 [启动指令](PROMPT_FOR_DOTS.md) 交给编码 Agent。按队列做完并验证一项后，直接做下一项；只在实际执行窗口允许时继续。Markdown 不会延长执行窗口，也不会创建定时唤醒。
